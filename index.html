Ready for Netlify Hosting

🚀 ส่งออกโค้ดทั้งหมด & เชื่อมต่อระบบจริงบน Netlify

ดาวน์โหลดไฟล์ index.html ฉบับสมบูรณ์พร้อมข้อมูลร้านค้าของคุณ หรือตั้งค่าเชื่อมต่อ Netlify Functions (EasySlip API) และ Email Webhook

🔌 ตั้งค่าเชื่อมต่อ API จริง (Production Mode)

ระบบจะส่งไฟล์รูปสลิปแบบ FormData ไปยัง Endpoint นี้แทนการจำลอง เพื่อซ่อน EASYSLIP_ACCESS_TOKEN ไว้บนเซิร์ฟเวอร์ Netlify อย่างปลอดภัย

📋 เช็กลิสต์นำเว็บขึ้น Netlify ภายใน 3 นาที
  1. กดปุ่ม "ดาวน์โหลดไฟล์ index.html" ด้านบน (หรือคัดลอกโค้ดทั้งหมดในหน้าต่างฝั่งขวาบันทึกเป็นไฟล์ index.html)
  2. สร้างโฟลเดอร์ใหม่ในคอมพิวเตอร์ชื่อ pinkflow-store แล้วนำไฟล์ index.html ใส่ไว้ด้านใน
  3. เข้าเว็บไซต์ app.netlify.com/drop แล้วลากโฟลเดอร์ไปวาง เว็บจะออนไลน์ทันที
  4. หากต้องการใช้ EasySlip ตรวจสลิปจริง ให้เพิ่ม EASYSLIP_ACCESS_TOKEN ในเมนู Environment variables ของ Netlify
💡 เคล็ดลับ: ข้อมูลสินค้า โลโก้ และธีมสีที่คุณปรับแต่งไว้ในหน้านี้ จะถูกฝังลงในไฟล์ index.html อัตโนมัติเมื่อกดปุ่มดาวน์โหลดค่ะ
